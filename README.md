# Happy Diwali, Nandita ✨

A personalized, cinematic Diwali wish made with vanilla JavaScript, CSS, SVG, and Canvas.

## The experience

- Animated golden diya, flickering flame, rangoli, lanterns, and starlight
- Personalized typography and a romantic message for Nandita
- Canvas fireworks with a heart-shaped finale
- A “Make a wish” interaction with a private love note
- Optional generative bell music (off by default)
- Responsive mobile layout and reduced-motion support
- Locally bundled fonts; no external assets or API keys required

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
npm run preview
```
